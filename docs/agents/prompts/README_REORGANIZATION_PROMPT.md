# README Reorganization Prompt

Bu prompt, repository dokümantasyonunu düzenlemek için kullanılır.

Hedefler:

- Root'u sade tut.
- Güncel kullanım, mimari, operasyon, agent ve arşiv belgelerini ayır.
- Eski path referanslarını yeni doküman ağacına çevir.
- Kırık relative link bırakma.

Çalışmaya başlamadan önce [docs/README.md](../../README.md) ve [docs/archive/README.md](../../archive/README.md) yapısını kontrol et.
