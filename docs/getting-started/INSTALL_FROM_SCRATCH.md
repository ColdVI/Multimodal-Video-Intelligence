# Sıfırdan Kurulum

Bu doküman, repoyu temiz bir makinede ayağa kaldırmak için kısa bir yol haritasıdır.

1. [README.md](../../README.md) içindeki hızlı başlatma bölümünü okuyun.
2. Python bağımlılıklarını `requirements.txt` üzerinden kurun.
3. Docker Compose ve yerel servisleri `make infra-up` ve `make schema` ile hazırlayın.
4. Veri gerekiyorsa resmî downloader ve veri sözleşmesini kullanın.
5. Son olarak [docs/operations/STATUS.md](../operations/STATUS.md) ile doğrulanan son durumu kontrol edin.

Detaylı operatör akışı için [docs/getting-started/OPERATOR_QUICKSTART.md](OPERATOR_QUICKSTART.md) dosyasına bakın.
